# Godot Project

This directory is the complete Godot project root. Open this directory in the editor; `project.godot`, scenes, data, scripts, and tests all live below it.

Godot-native tests live under `tests/`. See `docs/TESTING.md` for:
- why we use project-local tests (and not engine-internal doctest),
- test categories and guarantees,
- run commands for one test, all Godot tests, and Python QA checks.
